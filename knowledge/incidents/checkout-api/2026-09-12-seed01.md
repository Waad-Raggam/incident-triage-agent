# Incident 2026-09-12-seed01 (checkout-api)

Alarm: checkout-api-errors
Opened: 2026-09-12T09:14:00Z  Resolved: 2026-09-12T09:41:00Z
ServiceNow: INC0010007
Note: seed example written for this project, not a real outage.

## Root cause
Version 14 of checkout-api changed the payment client connection pool from 50 to 10. Under normal traffic
the pool ran out and about 40% of checkouts failed with PaymentGatewayError: connection pool exhausted.

## Evidence
- payment_failed lines with error "PaymentGatewayError: connection pool exhausted (max=10)", all version 14
- live alias moved from version 13 to 14 at 09:09, five minutes before the alarm

## Fix applied
Rolled back the live alias from version 14 to 13. Errors stopped within two minutes.

## Remediation action
rollback_deploy
